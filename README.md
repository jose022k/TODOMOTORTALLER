# Todomotortaller — Sistema Web PWA de Seguimiento de Motos

## Descripción general

Plataforma web PWA para el taller Todomotortaller. 1703, C.A. Permite gestionar órdenes de servicio, motos, clientes y mecánicos, con seguimiento en tiempo real y notificaciones automáticas.

## Stack Tecnológico

- Backend: Python · FastAPI · SQLAlchemy
- Frontend: Vue.js (PWA)
- Base de datos: PostgreSQL (Supabase)
- Archivos: Cloudinary
- Notificaciones: Web push
